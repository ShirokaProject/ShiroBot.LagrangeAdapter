## 语义与边界

- 通用历史接口 beforeMessageId 为排他序号；QQ 历史 cursor 为下一页起始序号。好友历史首页使用上游 GetRoamMessage，后续按序号 GetC2CMessage 查询。
- 群申请列表从全局普通群通知中筛选目标群，页面可能为空但仍有下一页 cursor；过滤通知可通过 GetNotificationsAsync(isFiltered: true) 查询。
- 文件夹创建的上游方法不返回 ID：适配器比较创建前后的列表，只在找到唯一新增同名文件夹时返回 ID，否则明确报错让调用方刷新列表，避免返回错误 ID。
- 禁言和踢人等返回 bool 的上游方法，false 会转换为操作失败。批量禁言顺序执行，取消时按 SDK 返回部分结果，正在等待响应的项标记 Unknown。
- 最新上游时间字段使用 Unix 秒，已同步转换为 SDK DateTimeOffset。

上游没有 SDK 对应方法的能力（例如在线状态、自定义状态、群打卡/待办、转让群、群备注、文件空间统计、客户端密钥、登录验证提交等），可通过 GetExtension<BotContext>() 使用上游公共接口。通用 SDK 不新增这些平台私有方法。

当前验证包含接口签名、预取消分发、协议 false 处理、时间和文件/申请模型映射等离线测试。真实 QQ 登录和功能调用尚需账号验证，不把编译成功视为在线功能验证。
