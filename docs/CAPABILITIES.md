版本：0.1.5。基于 ShiroBot.SDK 1.0.3 和固定的 Lagrange.Core 子模块；参考 Acidify/Yogurt 的 Milky API、协议结构及事件转换补齐内核公共 API 的缺项。新增协议代码位于 `src/Protocol`，内核修改由 `patches/lagrange-login-challenges.patch` 管理，不改变子模块 gitlink。

## 登录和凭据

- PC：二维码、密码、保存会话恢复。AndroidPhone / AndroidPad：密码、保存会话恢复、滑块、短信二次验证、新设备验证链接。
- Android 使用独立签名器及 Android AppInfo，不复用 Mac 签名算法。签名地址支持版本路径 Token 或 Bearer，两者择一。
- 滑块由独立的 [本地 Ticket helper](../captcha-helper/README.md) 提供前端，验证码组件仍来自腾讯。验证请求、取消及过期隔离，不接受旧页面提交。
- Android 密码、滑块、短信提交和 A1 续期分别需要签名服务支持 `810_9`、`810_2`、`810_7`、`810_f`，短信发码还需要 `810_8` 的 TLV553。
- 新登录不立即重复 A1 续期；每日自动续期，页面提供“刷新凭据”和只读“检查连接”。网络断线可在配置允许时以保存会话有限重试，不自动重发密码/短信。
- 实验性的免密码短信入口：检查账号 → 发码 → 校验 → 登录票据交换。已有离线状态机与清理检查，尚无腾讯实际免密码登录成功证据。Android 扫码、AndroidWatch 未实现。

## 语义和错误处理

- 通用历史 `beforeMessageId` 为排他序号；QQ 历史 cursor 为下一页起始序号。私聊首页用漫游记录，后续用序号查询。
- 群申请页从全局通知筛选目标群，空页仍可能有下一页。好友申请使用 Yogurt 的 `0x5cf_11` / `0xd69_0`，不再调用返回 UID 错误的旧 `0xFE1_2`。
- 创建文件夹后比较前后列表，仅在唯一识别新增同名文件夹时返回 ID。
- OIDB 外层错误、文件操作内层错误、Web API 错误及内核 false 均转换为失败。批量禁言顺序执行，取消时保留部分结果。
- 请求最长等待 30 秒；响应、错误、断线和销毁立即清理计时器，避免热重载被超时任务持有。
- 上游时间为 Unix 秒，转换为 SDK DateTimeOffset。无法解析或服务器拒绝时报告真实错误，不用空列表/空签名冒充成功。

## 验证

离线检查涵盖原有宿主契约、登录状态机、Android/PC 签名 HTTP 契约、AppInfo、取消、协议字节样本、错误返回、表情实际编码、推送映射、Web 响应、登录页面及 Ticket helper。卸载回归额外覆盖带有待处理请求计时器的实例，测试过程不联系腾讯。

实机 AndroidPad 已完成密码 → 滑块 → 短信二次验证 → 上线、保存会话恢复和真实 A1 凭据续期。好友、群、置顶、收藏表情、普通/过滤好友申请、新版表情目录，以及测试群成员/文件/公告/精华共 11 项只读在线检查通过；凭据刷新后热重载回收成功并恢复在线。群管理、删除好友等写接口的协议契约通过不等于所有写接口均已对真实账号逐项操作，权限和腾讯风控也不由适配器绕过。
